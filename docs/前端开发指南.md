# 前端开发指南文档

## Context

本文档供前端开发人员使用，详细说明后端接口和功能。

---

## 1. 项目概述

基于多模态大模型与双路检索的多模态 RAG 知识库系统。

- **后端地址**: `http://localhost:9090`
- **前端开发服务器**: `http://localhost:5173`
- **CORS**: 支持 `localhost:5173-5175` 和 `127.0.0.1:5173-5175`

---

## 4. 后端 API 详解

### 4.1 知识库 API (`/api/knowledge-base`)

#### GET `/api/knowledge-base/list`

获取已上传图片列表。

**参数:**
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| skip | int | 0 | 跳过数量 |
| limit | int | 100 | 返回数量 |

**返回:** `ImageRecord[]`

```json
[
  {
    "id": "uuid-string",
    "file_path": "storage/uuid.jpg",
    "upload_time": "2026-04-01T12:00:00",
    "generated_description": "图片描述文本",
    "status": "Completed",
    "source_dataset": "coco"
  }
]
```

#### POST `/api/knowledge-base/upload`

上传图片并生成描述。

**请求体:** `multipart/form-data`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| files | File[] | 是 | 图片文件（JPG/PNG） |
| split | string | 否 | 默认 "custom" |
| source_dataset | string | 否 | 来源数据集 |

**返回:** `UploadImagesResponse`

```json
{
  "uploaded": 1,
  "failed": 0,
  "results": [
    {
      "id": "uuid-string",
      "file_name": "image.jpg",
      "status": "Processing"
    }
  ]
}
```

### 4.2 搜索 API (`/api/search`)

#### POST `/api/search/text-to-image`

文本→图像搜索。

**请求体 (JSON):**

```json
{
  "query": "一只可爱的猫",
  "top_k": 10
}
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| query | string | 必填 | 搜索文本 |
| top_k | int | 10 | 返回数量 |

**返回:**

```json
{
  "query": "一只可爱的猫",
  "results": [
    {
      "id": "uuid-string",
      "file_path": "storage/uuid.jpg",
      "description": "一只橘色猫咪在阳光下打盹",
      "score": 0.253
    }
  ]
}
```

> **注意:** score 为相似度分数，越小表示越相似。

#### POST `/api/search/image-to-image`

图像→图像相似度搜索。

**请求体:** `multipart/form-data`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | File | 是 | 查询图片 |
| top_k | int | 否 | 默认 10 |

**返回:**

```json
{
  "query_description": "图片描述由MLLM生成",
  "results": [
    {
      "id": "uuid-string",
      "file_path": "storage/uuid.jpg",
      "description": "相似的图片描述",
      "score": 0.182
    }
  ]
}
```

### 4.4 RAG 聊天 API (`/api/rag`)

#### POST `/api/rag/chat`

RAG 问答（非流式）。

**请求体:** `multipart/form-data`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| query | string | 是 | 问题文本 |
| top_k | int | 否 | 默认 5，检索数量 |
| session_id | string | 否 | 会话 ID，多轮对话 |
| image | File | 否 | 视觉查询图片 |

**返回:**

```json
{
  "answer": "根据检索到的图片，这是一只可爱的橘猫...",
  "results": [
    {
      "id": "uuid-string",
      "file_path": "storage/uuid.jpg",
      "description": "橘色猫咪",
      "score": 0.182
    }
  ],
  "sources": [
    {
      "source_type": "image",
      "source_id": "uuid-string",
      "title": "cute_cat.jpg",
      "file_path": "storage/uuid.jpg",
      "content": null,
      "score": 0.182,
      "metadata": {}
    }
  ],
  "session_id": "session-uuid"
}
```

#### POST `/api/rag/chat/stream`

RAG 聊天（流式 SSE）。

**请求体:** 同 `/api/rag/chat`

**返回:** Server-Sent Events

```
data: {"type": "session", "session_id": "..."}\n\n
data: {"type": "content", "content": "根据"}\n\n
data: {"type": "content", "content": "检索"}\n\n
data: {"type": "content", "content": "到的"}\n\n
...
data: {"type": "results", "results": [...], "sources": [...]}\n\n
data: [DONE]\n\n
```

**事件类型:**

| type | 说明 |
|------|------|
| session | 包含 session_id |
| content | 流式文本片段 |
| results | 检索结果 |
| sources | 来源列表 |
| done | 结束标记 |

```typescript
import { http } from './http';
import type { SearchResultItem, ChatSourceItem, Session, Message } from './types';

export interface ChatOptions {
  query: string;
  topK?: number;
  sessionId?: string;
  image?: File;
}

export interface ChatResponse {
  answer: string;
  results: SearchResultItem[];
  sources: ChatSourceItem[];
  session_id: string;
}

export async function ragChat(options: ChatOptions): Promise<ChatResponse> {
  const form = new FormData();
  form.append('query', options.query);
  form.append('top_k', String(options.topK ?? 5));
  if (options.sessionId) form.append('session_id', options.sessionId);
  if (options.image) form.append('image', options.image);

  const { data } = await http.post('/api/rag/chat', form, {
    headers: { 'Content-Type': 'multipart/form-data' }
  });
  return data;
}

export async function ragChatStream(
  options: ChatOptions,
  onMessage: (type: string, data: any) => void
): Promise<void> {
  const form = new FormData();
  form.append('query', options.query);
  form.append('top_k', String(options.topK ?? 5));
  if (options.sessionId) form.append('session_id', options.sessionId);
  if (options.image) form.append('image', options.image);

  const response = await fetch('http://localhost:9090/api/rag/chat/stream', {
    method: 'POST',
    body: form
  });

  const reader = response.body?.getReader();
  if (!reader) throw new Error('No response body');

  const decoder = new TextDecoder();
  let buffer = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    buffer += decoder.decode(value, { stream: true });
    const lines = buffer.split('\n');
    buffer = lines.pop() ?? '';

    for (const line of lines) {
      if (line.startsWith('data: ')) {
        const jsonStr = line.slice(6).trim();
        if (jsonStr === '[DONE]') {
          onMessage('done', null);
          return;
        }
        try {
          const parsed = JSON.parse(jsonStr);
          onMessage(parsed.type, parsed);
        } catch (e) {
          // Ignore parse errors
        }
      }
    }
  }
}
```

## 7. 图片 URL 构造

图片从后端静态文件服务提供:

```typescript
/**
 * 将 file_path 转换为可访问的 URL
 * @param filePath 后端存储路径，如 "storage/uuid.jpg"
 * @returns 可访问的完整 URL
 */
export function imgSrc(filePath: string): string {
  // 统一使用正斜杠
  const normalized = filePath.replace(/\\/g, '/');
  const idx = normalized.indexOf('storage/');
  if (idx !== -1) {
    return `http://localhost:9090/static/${normalized.slice(idx + 'storage/'.length)}`;
  }
  return '';
}

/**
 * 获取文档图片 URL
 */
export function docImgSrc(docId: string, filename: string): string {
  return `http://localhost:9090/static/docs/${docId}/${filename}`;
}
```

> 后端静态文件挂载于 `/static`（见 `backend/app/main.py`）。

## 8. 认证与安全

- **无认证机制**: 当前实现没有身份验证
- **CORS**: 仅允许指定来源访问（`localhost:5173-5175` 和 `127.0.0.1:5173-5175`）
- **文件上传**: 后端验证文件类型（图片: JPG/PNG/GIF/WebP，文档: 仅 PDF）

> **警告:** 当前实现适合开发/内部使用，生产环境需自行添加认证机制。

```typescript
}

function handleApiError(error: unknown): string {
  if (error instanceof AxiosError<ApiError>) {
    return error.response?.data?.detail ?? error.message;
  }
  if (error instanceof Error) {
    return error.message;
  }
  return 'Unknown error';
}
```

## 12. 常见问题

### Q: 上传图片后状态一直是 Processing？

A: 图片处理需要时间，如果长时间处于 Processing 状态，请检查:
1. 后端日志是否有错误
2. MLLM 服务是否正常运行
3. ChromaDB 是否可写

### Q: 搜索结果为空？

A: 可能原因:
1. 知识库中没有图片
2. 查询文本与图片描述不匹配
3. top_k 值太小

### Q: 流式响应中断？

A: 检查:
1. 网络连接是否稳定
2. 后端服务是否正常
3. 请求是否超时（默认 60s）

### Q: 文档解析失败？

A: 确保:
1. 文件是有效的 PDF 格式
2. PDF 未加密或受保护
3. 文件大小在限制内（默认 32MB）
